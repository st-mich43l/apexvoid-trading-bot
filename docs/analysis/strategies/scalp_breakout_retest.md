# Scalp Breakout Retest Strategy V2

`scalp_breakout_retest` is the distinct M5-context/M1-trigger scalp thesis.
M5 establishes a bounded compression box; the configured number of M1 closes
must accept beyond one edge; a subsequent M1 retest must touch and hold it.
Entry is the retest band, invalidation is back through the edge and target is
configured R. Identity anchors the M5 box and direction. Wick-only breaks,
mixed acceptance, failed retests and stale setups reject. Rollout remains
disabled and does not alter Python live policy.
